# Smart-Transaction-Risk-Detectors
This program analyzes a user’s daily digital payment transactions to determine whether their spending behavior is normal or potentially suspicious. Each transaction is categorized based on the amount, and patterns like frequent transactions, high total spending, or multiple high-risk transactions are evaluated. A personalized risk scoring system is used, where each suspicious pattern increases the risk score by two points. Based on the total score, transactions are classified as Low Risk, Moderate Risk, or High Risk. The program then generates a detailed summary including transaction categories, total amount spent, and final risk assessment.
